% ==================== Description ====================
\noindent
This document reproduces, in full, the Python script (\texttt{RF.py}) used to
train and evaluate the Random Forest regression model reported in the
manuscript. The model predicts the SO\textsubscript{2} concentration from four
input features---relative humidity, absorbent weight, temperature, and
time. The workflow comprises: (i) loading the experimental data, (ii)
min--max normalisation of the features and target, (iii) a 70/20/10
train/validation/test split, (iv) training a tuned Random Forest regressor,
(v) computing the standard error metrics (MSE, RMSE, $R^2$, MAE), and
(vi) generating a cross-validated learning curve. The code is reproduced
verbatim below; line numbers are provided for ease of reference.

\vspace{0.5em}
\noindent\textbf{Software:} Python~3 with \texttt{pandas}, \texttt{numpy},
\texttt{scikit-learn}, and \texttt{matplotlib}.
